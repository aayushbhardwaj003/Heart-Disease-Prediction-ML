# Heart Disease Prediction Using Machine Learning

This project predicts the likelihood of heart disease using Machine Learning algorithms and patients clinical data.

## Features
- Data preprocessing
- Exploratory Data Analysis
- Model training and evaluation
- Prediction system

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
-Deep Neural Network

## How to Run

1. Install dependencies
2. Open the notebook
3. Run all cells
